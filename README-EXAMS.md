# Qas.nur — System Exams v1.5

This ZIP preserves the existing Adult Health I files and adds six independent examinations:
- Cardiovascular, Respiratory, Gastrointestinal, Endocrine, Renal & Urinary: 25 questions each.
- Comprehensive Adult Health I: 50 questions (8 drawn from each system and 10 from JUST Clinical Core).

The bank contains 135 original authored question items; the comprehensive exam draws from the same bank. Questions are shuffled, options shuffled, all questions require an answer, and full explanations appear after submission. Scores are not transmitted or stored on a server. This is an educational draft, not a professionally validated examination.

Deployment: Extract ZIP and upload its site files to the root of the GitHub Pages repository, replacing matching files. Keep index.html and JS/CSS files at the same directory level. Verify System Exams on mobile and desktop after publishing.

Owner analytics dashboard is NOT implemented in this release. Secure private analytics requires an authenticated analytics provider or backend. The existing QR code is separate and points to the site URL; it does not need code changes to the site.
